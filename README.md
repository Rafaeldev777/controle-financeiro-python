# 💰 Controle Financeiro em Python

> Aplicativo de controle financeiro em Python desenvolvido para registrar receitas, despesas e acompanhar o saldo de forma prática.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3** (Lógica principal da aplicação)
- **Git & GitHub** (Controlo de versões)

---

## 🚀 Funcionalidades

- 📥 **Registo de Entradas (Receitas):** Adiciona valores recebidos com descrição.
- 📤 **Registo de Saídas (Despesas):** Regista gastos e categoriza os pagamentos.
- 📊 **Cálculo de Saldo:** Apresenta o saldo acumulado e atualizado.
